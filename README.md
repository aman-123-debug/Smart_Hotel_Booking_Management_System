Smart Hotel Booking Management System with Face Recognition

About the Project
The Smart Hotel Management System with Face Recognition is a web-based application developed as a final-year academic project. It aims to simplify hotel room booking, guest registration, booking management, and guest verification using face recognition technology.

 Features
- User registration and login
- Browse hotel rooms and room types
- Online room booking
- Booking history and cancellation
- Payment workflow
- Face registration and verification
- MySQL database integration
- Backend APIs using Node.js and Express.js

Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL
- Face Recognition: face-api.js
- Authentication: bcryptjs

Project Structure
- `Backend/` – Backend server and API logic
- `index.html` – Home page
- `Rooms.html` – Room listing page
- `booking.html` – Room booking page
- `register.html` – User registration
- `login.html` – User login
- `payment.html` – Payment page
- `Booking_History.html` – Booking history

Installation and Setup
1. Install Node.js and MySQL.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Install dependencies using `npm install` in the directory containing the relevant `package.json`.
5. Configure your local database credentials using a `.env` file, following the backend configuration.
6. Create the `smart_hotel` database and configure the required tables.
7. Start the backend with `node Backend/server.js` from the project root, if this matches your setup.
8. Open the frontend HTML pages in a browser.

Security
Do not upload database passwords, API keys, or other secret credentials. Keep the local `.env` file excluded from Git.

Project Purpose
This project demonstrates web development, database management, hotel booking workflows, and face recognition integration for academic learning.
